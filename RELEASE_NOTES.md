# SuperMEOW 1.3.1 Preview

Android 8.0+ · versionCode 14 · package `com.supermeow.preview`

This is a debug-signed Preview build. It installs separately from the Google Play app and is intended for trying the app, not as a production-signed update. Use Google Play for the store release.

Changes in 1.3.1:
- Fixed duplicate bottom navigation spacing.
- Kept mini-game scores and play area clear of system bars.
- Replaced corrupted bow-balance text with a drawable icon.
- Improved the reward-ad card layout.

The APK was built successfully and the associated source passed 17 tests. It has not been verified on every device. This APK predates the later R8 configuration changes.

Download the APK and SHA256SUMS.txt from the release assets. On Windows, verify the file with `Get-FileHash .\SuperMEOW-1.3.1-preview.apk -Algorithm SHA256`.

Google Play: https://play.google.com/store/apps/details?id=com.supermeow
